---
name: block-ai-commit
enabled: true
event: bash
pattern: git\s+.*commit\s+.*(-m\s+["'].*|.*)(claude|anthropic|co-authored-by[:\s]*(claude|ai|anthropic)|generated\s*(by\s+|with\s+)?ai|ai[\-\s]*(generated|assisted|powered)|copilot|gpt-?\d*|openai|chatgpt|llm|language\s*model|bard|gemini|cursor|codeium|tabnine|claude[\s-]*code)
action: block
---

**AI Reference Detected in Commit Message**

The command contains a reference to AI tools (Claude, Copilot, GPT, etc.) or a Co-Authored-By attribution to an AI agent.

**Detected Patterns:**
- `Claude`, `Anthropic`, `Claude Code`
- `Co-Authored-By: ... Claude/AI/Anthropic`
- `Copilot`, `GPT`, `GPT-4`, `OpenAI`, `ChatGPT`
- `Generated by AI`, `AI generated`, `AI assisted`, `AI powered`
- `LLM`, `Language Model`
- `Bard`, `Gemini`, `Cursor`, `Codeium`, `Tabnine`

**Required Action:**
Remove the AI reference from the commit message and retry.
