## NuGet Package

Install Bogoware.Monads via NuGet:

<Tabs>
  <TabItem label=".NET CLI">
    ```shell
    dotnet add package Bogoware.Monads
    ```
  </TabItem>
  <TabItem label="Package Manager">
    ```powershell
    Install-Package Bogoware.Monads
    ```
  </TabItem>
</Tabs>

## Supported Platforms

| Platform | Version |
|----------|---------|
| .NET Standard | 2.1 |
| .NET | 8.0, 9.0, 10.0 |

## Basic Usage

<Steps>

1. Add the namespace to your code:

   ```csharp
   using Bogoware.Monads;
   ```

2. You're now ready to use `Result<T>` and `Maybe<T>` in your projects.

</Steps>
